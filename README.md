# React Clock Dashboard

A React clock dashboard with analog and digital displays, timezone selection, and 12/24 hour format toggle.

## Features

- Analog clock
- Digital clock
- Timezone selection
- 12-hour / 24-hour mode

## Tech Stack

- React 18
- React DOM
- CSS
